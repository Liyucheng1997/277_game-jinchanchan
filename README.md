# 金铲铲小战棋

一个纯网页版的自走棋小游戏，不需要安装任何东西——**双击 `index.html` 即可开始游戏**（推荐 Chrome / Edge）。

## 玩法

- **目标**：从 1-1 打到 5-5，击败最终 BOSS 通关；之后还可挑战无尽模式。
- **购买**：点击底部商店卡牌购买棋子（D 键刷新商店，2 金币）。
- **上阵**：把棋子从备战席拖到棋盘下半区；人口上限 = 等级（F 键买经验升级）。
- **升星**：集齐 3 个相同棋子自动合成升星（3 个 1★ → 2★，3 个 2★ → 3★），属性 ×1.8/星。
- **装备**：每隔几回合掉落装备，拖到棋子身上（每人最多 3 件）；稀有的**金铲铲**全属性加成。
- **出售**：把棋子拖到右侧「出售」区回收金币。
- **敌情**：备战期棋盘上方的红色虚影就是下一波敌人，提前针对布阵！
- **经济**：每回合 +5 金币；每存 10 金币 +1 利息（上限 5）；连胜 / 连败有额外奖励。

## 羁绊

| 羁绊 | 效果 |
|---|---|
| 🔥 烈焰 (2/4) | 普攻点燃敌人，持续真实伤害 |
| ❄️ 寒冰 (2/4) | 普攻冰缓敌人攻速 |
| 🌿 森林 (2/4) | 全队每秒回血 |
| 🛡️ 战士 (2/4) | 战士加护甲 |
| 🏹 射手 (2/3) | 射手加攻速 |
| 🔮 法师 (2/4) | 法师加法强 |
| 🗡️ 刺客 (2/3) | 开战跳后排 + 暴击 |

## 快捷键

- `D` 刷新商店　`F` 购买经验　`空格` 开始战斗

## 技术

纯 HTML / CSS / 原生 JavaScript，零依赖。代码结构：

- `js/data.js` — 英雄 / 羁绊 / 装备 / 敌方波次数据
- `js/combat.js` — 自动战斗模拟引擎 + 英雄技能
- `js/ui.js` — 界面渲染、拖拽、战斗动画
- `js/game.js` — 经济系统、商店、回合流程、音效（WebAudio 合成）
