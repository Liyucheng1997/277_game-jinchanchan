# 金铲铲 · 时空裂痕 / 福星本地练习版 v1.8

## 新增：可选福星版本

点击右上角 **「切换版本」→「进入福星版本」**。原时空裂痕保留，两个版本各自保存一局进度；再次打开会进入上次选择的版本。切换自动保存，战斗中切换后恢复到本回合备战，保留已购买的英雄、金币和装备。旧版存档自动兼容；「重新开局」只替换当前版本的进度。

福星是基于现有引擎的**本地改编版**，不是历史福星赛季的完整复刻：沿用其他时空裂痕英雄、装备、经济和职业羁绊，卡池共 60 名英雄。新增塔姆、安妮，卡特琳娜、金克丝、瑟庄妮改为福星阵营；金克丝在此版本为 3 费，使用范围伤害和眩晕火箭。塔姆拥有减伤被动，安妮造成范围伤害并获得护盾。新角色目前使用本地二维肖像，其余角色复用现有模型。

- **3 福星**：开战时上阵三名不同福星英雄，弈士战斗失败或平局积累，胜利收菜。获得 `3 + 3n + n²` 金币，`n` 为积累败场数（奖励最多按 12 败计算）；每 3 败额外获得一件普通基础装备，最多四件。
- **6 福星**：胜利时额外获得 10 金币和一件随机成装（不含纹章及人口装备）。五名福星加一名福星天选即可激活六福。
- **福星天选**：未持有天选时，每次刷新有 40% 概率尝试将商店第一张符合条件的福星牌升级为天选；卡池必须还有两张。直接二星，费用为三张一星价格，预留三张卡池，福星人数额外 +1。只能持有一名，出售后可再次遇到；升三星保留天选。天选仅在上阵时提供羁绊人数。
- 野怪与选秀不增减福星积累；暂时撤下福星保留积累，重新激活后才能继续积累或收菜。使用开战快照结算，战斗中购买不会影响本场收益。
- 奖励进入福袋，可与其他未领战利品累计；点击让小精灵领取后才加入钱包。左侧面板显示积累、预计奖励及已收菜次数，点击可查详细规则。

天选出现率、奖励表和新英雄数值为本地设计。机制方向参考 Riot 的 [Fates 机制介绍](https://teamfighttactics.leagueoflegends.com/en-au/news/game-updates/tft-fates-mechanic-and-origins/) 与 [Fates 复盘](https://teamfighttactics.leagueoflegends.com/en-us/news/dev/dev-teamfight-tactics-fates-learnings/)。素材来源见 `assets/fortune/sources.json`。电脑继续使用原有经营逻辑，部分电脑优先招募福星；天选商店和福袋奖励目前用于玩家。

验证命令：`node --test tests/engine.test.cjs tests/fortune.test.cjs`。浏览器验证：`node scripts/verify-fortune.cjs`，与已有界面验证一样支持 `PLAYWRIGHT_MODULE` 指定 Playwright 路径。

## TypeSafe Jev AI 接管

右上角新增 **「AI 接管」**。开启后，TypeSafe 的 Jev 会以最终第一名为目标，根据每一步的结构化对局状态，从游戏生成的合法动作中选择选秀、购买、升级、刷新、装备、阵容替换、站位或结束经营。状态包含当前/候选羁绊、升星进度、英雄职责与技能、装备效果、利息变化、等级商店概率、血量压力和对手预览；站位支持标准前后排、左右抱团与分散阵型。结束经营时会自动补满上阵人口并立即点击准备就绪。规则校验和动作执行仍由本地游戏完成。每回合最多请求 12 次，达到上限也会强制准备就绪，状态变化时会丢弃过期响应，服务异常时自动停止接管并保留手动操作。

API 密钥只由本地 Node 服务读取，不会写入网页代码、浏览器存档或 Git。运行 `npm start` 并打开网页后，点击 **「AI 接管」** 或旁边的齿轮，在密码框中粘贴 Jev API 密钥即可。密钥保存在本机的 `.typesafe.local.json`（已加入 `.gitignore`），保存后立即生效。

也可以选择写入 Windows 用户环境变量；环境变量优先于网页保存的配置，设置后需重启终端或 Codex：

```powershell
[Environment]::SetEnvironmentVariable('TYPESAFE_API_KEY', '你的-TypeSafe-密钥', 'User')
```

然后在项目目录启动：

```powershell
npm start
```

打开 <http://127.0.0.1:8765/>。可选的 `TYPESAFE_MODEL` 默认为 `jev-latest`，可选的 `TYPESAFE_ENDPOINT` 可覆盖官方 API 地址。不要把密钥写进 `js/` 文件、HTML、Git 仓库或浏览器 `localStorage`。双击 `index.html` 仍可手动游玩，但网页配置和 AI 接管需要通过本地 Node 服务使用。

界面沿用深色青绿与旧金色，在原有风格上优化适度圆角、面板层次、间距和按钮质感，覆盖棋盘、商店、排名、装备区、选秀和图鉴。独立样式在 `theme.css`，不影响对局规则；保留卡牌费用颜色和升星提示，并支持系统的减少动态效果设置。

```powershell

```

打开 <http://127.0.0.1:8765/>。建议使用横屏或最大化浏览器；界面按 1600 × 900 等比缩放。窄屏可玩，但文字和操作区域会较小。

## 对局流程

1. **共享选秀**：点击英雄，将英雄及其装备带回棋盘。后续选秀中，低血量的电脑弈士先选。
2. **备战**：点击商店购买英雄；先点击英雄再点击目标格，或直接拖动。可上阵区域是下半场 7 × 4 格，备战席有 9 格。支持交换站位和一键上阵。
3. **战斗**：35 秒后自动开战，也可点击「准备就绪」。暂停时点击准备就绪会继续战斗。战斗使用六角寻路、普攻、法力、技能、控制、护盾与装备效果，可切换双倍速度、查看伤害统计。
4. **奖励与经营**：野怪掉落法球，点击法球让小精灵走过去领取，或点击棋盘空地／右键地面移动，靠近后自动拾取金币和装备。备战和战斗中均可拾取，暂停时移动也暂停。未领取的奖励会累计；每存 10 金币提供 1 利息，最多 5 金币，另有基础收入和连胜/连败奖励。
5. **淘汰**：PvP 失利扣血，生命归零淘汰，最后的幸存者获胜。右侧可查看排名与电脑阵容。

## 英雄与装备

- 豪侠按开战时上阵阵容结算，仅弈士战斗触发，输赢均掉宝箱。点击宝箱让小精灵前往领取；3 豪侠提供 0–4 金币（可能空箱），5 豪侠额外提供 3 金币，并有 30% 概率获得一件非纹章装备（含基础装备）。这是本地近似掉落规则。未领取奖励累计保存，领取前不计入金币与利息；整局结束自动领取剩余奖励。

- 三个同名、同星英雄自动升星，最高三星。升星时多余装备返还装备区。商店标记已有牌、买入升二星／三星及同店可凑齐的牌；棋盘和备战席标记对子。星级放在脚下放大显示，装备放在头顶。
- 战斗中可购买英雄、刷新／锁定商店、购买经验，以及移动、出售和装备备战席英雄、合成库存装备。开战时的阵容独立参与当前战斗，经营和升星结果用于下一场。
- 每名英雄最多装备三件；小件会与已有小件自动合成。也可以在装备区先后点击两个小件合成。拖着装备悬停到另一个小件或英雄上，会先显示合成结果、属性和效果；松手才执行，Esc 取消。
- 选中英雄按 E 出售，或把英雄拖到下方招募栏：拖动时招募栏临时变为出售区，显示英雄、星级和售价，松手出售；移出后松手或按 Esc 取消。装备返还装备区，对应数量的英雄送回共享卡池。
- 右键英雄查看属性和技能；「英雄图鉴」支持名称、羁绊与费用筛选，并查看三个星级的数据。
- 「合成图鉴」展示基础装备组合及成装效果。同名英雄只计一次羁绊，不能给已有对应羁绊的英雄重复添加转职。

## 素材和实现范围

- 英雄属性、技能描述、羁绊、装备配方与对应图标：来自[金铲铲官网资料库](https://jcc.qq.com/#/hero)，快照日期为 **2026-09-09**，版本标识为 **1.0.0-S1**，不是当前赛季数据。
- 原始数据保存在 `assets/data/`，导入结果为 `js/official-data.js`；每张导入图片的来源记录在 `assets/data/manifest.json`。
- 棋盘使用已下载的经典竞技场参考图，来源地址同样记录在素材清单中。
- 部分野怪保留旧版 AI 图片或符号占位；默认音效仍为 WebAudio 合成，现已区分购买、出售、刷新、升星、装备、胜负提示，降低施法音量并限制密集重复播放。
- 原版音效尚未接入：本次未找到可核实的独立原版音效文件。支持将已取得的 MP3、WAV 或 OGG 放入 `assets/audio/`，在 `js/audio-sources.js` 为 buy、sell、refresh、combine、cast、win、lose、item 配置相对路径，即优先播放对应文件；播放失败自动回退合成音。

**当前是可完整进行对局的本地练习版，尚未达到原作严格一比一复刻。** 58 位英雄已接入 LoL 默认模型与骨骼动画。没有原版语音、联网匹配；野怪数值、AI 经营、战斗配对、部分技能时序与装备细节是本地近似实现。官网描述可用于查阅，但不代表每项战斗细节已逐帧还原。

### 全英雄 3D 试战

启动本地 HTTP 服务后，打开 `http://127.0.0.1:8765/?demo=heroes`。可选择任意英雄单独试战，或使用混合阵容、「换一组」「待机展示」。`?demo=garen` 保留盖伦入口。试战不读取或写入正常对局存档，返回正常对局恢复原存档。

正常棋盘和备战席支持全部 58 位英雄。统一提亮角色并轻微降低对比度，改善肤色和暗部可见度。接入待机、移动、普攻、死亡以及可用的施法动作；被动技能英雄沿用普攻。豹女、蜘蛛、龙女、纳尔、乌鸦支持第二形态；杰斯和金克丝支持对应武器动作切换；蜘蛛召唤物、露露皮克斯、千珏狼灵也有模型。缺少独立变身过渡动作时直接切换形态，乌鸦死亡使用人形动作。伙伴的位置是本地近似布局。

66 份模型（58 位英雄与 8 份附属资源）经过动画裁剪、缓冲区去重，由约 412.6 MiB 减至 106.2 MiB；保留的模型、骨骼、贴图、动画数值保持原数据。运行时按需加载，最多 3 个并行下载；模型首次下载后写入浏览器本地缓存，再次使用直接读取本机，刷新页面后也有效。底部「下载全部模型到本地」可预存全部 66 份模型（约 106.2 MiB），首次下载仍需联网；清除网站数据或浏览器回收缓存后需要重新下载。模型缓存不等于整个网页离线可用。模型按内容哈希校验和更新，缓存不可用时回退网络加载。角色按 160×160 显示尺寸渲染，首次初始化分帧执行，完全消失的死亡角色停止绘制。跨回合保留 3 份未使用模型缓存，其余释放。模型加载失败或 WebGL 不可用时显示原头像；`?models=off` 可关闭 3D。双击 HTML 的 `file://` 模式保留二维玩法，3D 请通过 HTTP 服务访问。

资源来自 [Khada 模型查看器](https://modelviewer.lol/)，属于 Riot Games。每份资源的来源和原始校验值保存在对应目录的 `source.json` 或形态 JSON；裁剪后的校验值、动画列表在 `*.runtime.json`。动作配置见 `assets/models/manifest.json`。

**这些是 LoL 模型候选，尚未逐个匹配金铲铲时空裂痕的历史模型版本。原版技能粒子、材质效果和音效尚未还原。** 现有本地技能特效继续使用，盖伦光环也是临时效果。模型渲染和动作可运行不等于原作一比一复刻。

重建流程（Python 3、Node.js）：

```powershell
python scripts/import-models.py
python scripts/import-model-forms.py
python scripts/configure-models.py
python scripts/optimize-models.py
npm install --prefix tmp/3d three@0.180.0 esbuild@0.25.9 --no-audit --no-fund
node scripts/build-3d.cjs
python tests/models.test.py
```

原始完整下载保留在 `tmp/models-original/`，不作为运行时资源。Three.js 已本地打包，许可证为 `js/vendor/THREE-LICENSE.txt`；运行时不依赖外部 CDN。浏览器集成检查脚本 `scripts/verify-models.js` 在独立试战页运行，检查 58 位英雄关键动作的多个采样时刻、模型非空、形态切换和暂停，并生成模型总览。
