# 金铲铲 · 时空裂痕本地练习版 v1.4

基于原有网页小游戏重构的单机自走棋。使用经典「时空裂痕」官网数据快照，包含 58 位英雄、25 个羁绊、57 件装备，与 7 名电脑弈士进行淘汰对局。

[在线游玩](https://liyucheng1997.github.io/277_game-jinchanchan/) · [v1.4 版本发布](https://github.com/Liyucheng1997/277_game-jinchanchan/releases/tag/v1.4) · [更新记录](CHANGELOG.md)

网站通过现有 GitHub Pages 从 `main` 分支根目录部署。发行版本使用 `v1.4` 标签；存档格式版本仍为 3，两者独立。

本版修复属性详情的装备与羁绊加成展示，按背景石板校准九格备战席，并增加同羁绊英雄与持有状态查询。

## 启动

界面沿用深色青绿与旧金色，在原有风格上优化适度圆角、面板层次、间距和按钮质感，覆盖棋盘、商店、排名、装备区、选秀和图鉴。独立样式在 `theme.css`，不影响对局规则；保留卡牌费用颜色和升星提示，并支持系统的减少动态效果设置。

双击 `index.html`，用 Chrome 或 Edge 打开即可游玩。图片和数据均在本地，不需要安装依赖。

也可在项目目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/>。建议使用横屏或最大化浏览器；界面按 1600 × 900 等比缩放。窄屏可玩，但文字和操作区域会较小。

## 对局流程

1. **共享选秀**：点击英雄，将英雄及其装备带回棋盘。后续选秀中，低血量的电脑弈士先选。
2. **备战**：点击商店购买英雄；先点击英雄再点击目标格，或直接拖动。可上阵区域是下半场 7 × 4 格，备战席有 9 格。支持交换站位和一键上阵。
3. **战斗**：35 秒后自动开战，也可点击「准备就绪」。暂停时点击准备就绪会继续战斗。战斗使用六角寻路、普攻、法力、技能、控制、护盾与装备效果，可切换双倍速度、查看伤害统计。
4. **奖励与经营**：野怪掉落法球，点击法球让小精灵走过去领取，或点击棋盘空地／右键地面移动，靠近后自动拾取金币和装备。备战和战斗中均可拾取，暂停时移动也暂停。未领取的奖励会累计；每存 10 金币提供 1 利息，最多 5 金币，另有基础收入和连胜/连败奖励。
5. **淘汰**：PvP 失利扣血，生命归零淘汰，最后的幸存者获胜。右侧可查看排名与电脑阵容。

## 英雄与装备

- 三个同名、同星英雄自动升星，最高三星。升星时多余装备返还装备区。商店标记已有牌、买入升二星／三星及同店可凑齐的牌；棋盘和备战席标记对子。星级放在脚下放大显示，装备放在头顶。
- 战斗中可购买英雄、刷新／锁定商店、购买经验，以及移动、出售和装备备战席英雄、合成库存装备。开战时的阵容独立参与当前战斗，经营和升星结果用于下一场。
- 每名英雄最多装备三件；小件会与已有小件自动合成。也可以在装备区先后点击两个小件合成。拖着装备悬停到另一个小件或英雄上，会先显示合成结果、属性和效果；松手才执行，Esc 取消。
- 选中英雄按 E 出售，或把英雄拖到下方招募栏：拖动时招募栏临时变为出售区，显示英雄、星级和售价，松手出售；移出后松手或按 Esc 取消。装备返还装备区，对应数量的英雄送回共享卡池。
- 右键英雄查看属性和技能；「英雄图鉴」支持名称、羁绊与费用筛选，并查看三个星级的数据。
- 「合成图鉴」展示基础装备组合及成装效果。同名英雄只计一次羁绊，不能给已有对应羁绊的英雄重复添加转职。

## 快捷键与存档

| 操作                     | 按键 |
| ------------------------ | ---- |
| 刷新商店，消耗 2 金币    | D    |
| 购买 4 经验，消耗 4 金币 | F    |
| 出售选中英雄             | E    |
| 准备就绪                 | 空格 |
| 关闭详情、取消选择       | Esc  |

备战操作、选秀和回合结算自动保存在当前浏览器。重新打开会暂停，点击顶部继续按钮或准备就绪即可继续。战斗中刷新会回到备战状态，并保留战斗期间已经购买的英雄、经验、商店、装备和领取的奖励。不同浏览器、地址或端口的存档不互通；浏览器禁止本地存储时仍可游玩，但不会保留进度。重新开局会替换当前存档。

## 素材和实现范围

- 英雄属性、技能描述、羁绊、装备配方与对应图标：来自[金铲铲官网资料库](https://jcc.qq.com/#/hero)，快照日期为 **2026-09-09**，版本标识为 **1.0.0-S1**，不是当前赛季数据。
- 原始数据保存在 `assets/data/`，导入结果为 `js/official-data.js`；每张导入图片的来源记录在 `assets/data/manifest.json`。
- 棋盘使用已下载的经典竞技场参考图，来源地址同样记录在素材清单中。
- 部分野怪保留旧版 AI 图片或符号占位；默认音效仍为 WebAudio 合成，现已区分购买、出售、刷新、升星、装备、胜负提示，降低施法音量并限制密集重复播放。
- 原版音效尚未接入：本次未找到可核实的独立原版音效文件。支持将已取得的 MP3、WAV 或 OGG 放入 `assets/audio/`，在 `js/audio-sources.js` 为 buy、sell、refresh、combine、cast、win、lose、item 配置相对路径，即优先播放对应文件；播放失败自动回退合成音。

**当前是可完整进行对局的二维本地练习版，尚未达到原作严格一比一复刻。** 棋子使用肖像而非原作三维模型，没有骨骼动画、原版语音、联网匹配；野怪数值、AI 经营、战斗配对、部分技能时序与装备细节是本地近似实现。官网描述可用于查阅，但不代表每项战斗细节已逐帧还原。继续提升原作视觉还原度需要对应的英雄、野怪模型与动作资源。

## 开发与验证

纯 HTML、CSS、原生 JavaScript，无前端运行时依赖。

| 文件                       | 用途                                     |
| -------------------------- | ---------------------------------------- |
| `js/official-data.js`      | 官方数据快照与图片路径                   |
| `js/data.js`               | 六角坐标、回合规则、卡池、野怪和辅助数据 |
| `js/combat.js`             | 玩家与电脑共用的固定步长战斗模拟         |
| `js/game.js`               | 经济、升星、装备、选秀、淘汰、存档       |
| `js/ui.js`                 | 界面、点击和拖动操作、图鉴、战斗动画     |
| `tests/engine.test.cjs`    | 战斗、卡池、物品守恒与流程回归测试       |
| `scripts/import-assets.py` | 从已保存的数据重新生成快照并补齐图片     |

运行测试（需要 Node.js）：

```powershell
node --test tests/engine.test.cjs
```

当前 18 项测试涵盖全部英雄三个星级的战斗完成、全部装备数值有效性、六角邻接、共享卡池守恒、满备战席合成、装备保留、完整对局淘汰、暂停开战、空阵容结算、战利品累计、转职限制、存档恢复和存储不可用，并增加战斗经营与战斗快照隔离、战斗购买存档、升星提示、无消耗合成预览和小精灵自动拾取检查。测试通过证明这些流程可运行，不代表已经验证所有原作数值与平衡性。

浏览器布局与出售交互验证：安装 Playwright 并确保 Microsoft Edge 可用后，在项目根目录运行 `node scripts/verify-ui.cjs`。也可用环境变量 `PLAYWRIGHT_MODULE` 指定已有 Playwright 模块路径。检查九格备战席底座对齐、三面板顶部对齐、拖拽出售、取消、E 出售和战斗中出售。

重新生成离线数据（需要 Python 及补齐缺失图片时的网络连接）：

```powershell
python scripts/import-assets.py
```

此命令使用仓库中的原始快照，不会自动切换赛季。`tmp/` 和 `official-page.tmp` 是上次资料采集的临时文件，运行游戏无需它们。
